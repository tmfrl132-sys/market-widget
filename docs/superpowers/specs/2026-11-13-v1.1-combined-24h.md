# 경제지표 위젯 v1.1 설계: S&P500·나스닥100 현물·선물 24시간 통합 차트

- 작성: 2026-11-13, android-dev(위젯 절). 수집기 절은 collector-dev 보고서를 따른다.
- 기준 코드: 브랜치 `feature/v1.1-combined-24h`(시작점 `main` 6adeafa = v1.0.0).
- 바탕 설계: `2026-10-30-market-widget-design.md`, `2026-11-06-v0.9-indicators.md`, `2026-11-12-v1.0-settings.md`. 이 문서에 없는 내용은 그 설계를 따른다.
- 표기: **[실측]** 2026-11-13 22:55~23:05 서울(뉴욕 금 08:55~09:05, 개장 전) Yahoo `range=5d&interval=5m`로 확인, **[미확인]** 배포 뒤 확인할 항목.

## 1. 사용자가 정한 것

1. S&P500 현물 + E-mini S&P500 선물, 나스닥100 현물 + E-mini 나스닥100 선물을 각각 하나의 24시간 연속 차트로 그린다.
2. 나스닥 카드는 나스닥 종합(`^IXIC`)에서 나스닥100(`^NDX`, id `NDX`, 이름 `나스닥100`)으로 바꾼다. `NQ=F`가 나스닥100 선물이기 때문이다.
3. `S&P 선물`(ES), `나스닥 선물`(NQ) 카드는 없앤다. 선물 시세는 합친 차트 재료로 기기가 계속 받는다.
4. 재검토 계획 승인: 최근 24시간 창, 명세 공식 그대로, 같은 시각 봉 연결, 정규장 배경 띠.
5. 보존: 카드 구성(숫자는 현물), 카드 작은 차트, 자동 새로고침, 설정, 디자인, data.json 구조.

## 2. 실측 자료 [실측]

| 항목 | 현물 `^GSPC`, `^NDX` | 선물 `ES=F`, `NQ=F` |
| --- | --- | --- |
| 봉 시간 | 09:30~16:00 ET. 봉 시각은 봉 시작. 가장 최근 장만 16:00 종가 봉이 있고 그 전 날들은 15:55가 마지막 | 18:00~17:00 ET. 매일 16:55/17:00~18:00이 빈다. 자정 00:00 봉도 없다(23:55 → 00:05, 10분) |

| `meta.previousClose` | 자료 안 마지막 장 바로 앞 장의 공식 종가(금 개장 전이면 수요일 종가 7,619.38) | 쓰지 않는다 |

| 마지막 봉 | 16:00 | 진행 중 봉의 시각이 실제 시각(예: 08:55:07) |

- range=5d의 마지막 정규장은 range=1d의 봉·시각·장 시간과 같다(개장 전 실측, 두 지수 모두 79개 일치).
- 가격 차이 ES−GSPC +0.28~0.31%, NQ−NDX +0.34~0.40%. 같은 시각 09:30 봉끼리 비교한 개장 이음매 차이 0.026~0.040%.
- 수요일 마지막 15:55 봉 종가(7,617.84)와 공식 종가(7,619.38)가 0.02% 다르다. 기준선은 공식 종가를 쓴다(4.4).

## 3. 지표 목록과 설정 이전

| 위치 | v1.0 | v1.1 |
| --- | --- | --- |
| `LIVE_SYMBOLS`, `BUILT_IN_NAMES` | 13개(ES, IXIC, NQ 포함) | 11개: KS11, KQ11, GSPC, NDX, VIX, KRW, DXY, TNX, CL, GC, BTC |
| `COMBINED_FUTURES` | - | GSPC → `ES=F`, NDX → `NQ=F` (카드 아님) |

- 설정 이전(`migrateSettings`): `IXIC` → `NDX`(순서 자리, 켜기·끄기를 이어받음), `ES`·`NQ`는 `order`·`hidden`에서 지운다. 추가 종목은 건드리지 않는다. 이미 옮긴 설정은 같은 객체를 돌려준다.
  - 위젯이 그릴 때 읽는 `SettingsStore.read()`는 메모리에서만 옮긴다(파일 쓰기 없음).
  - `update`는 파일 원본과 비교해 쓰므로 `update { it }`가 이전 저장이다. 갱신 작업(`RefreshWorker`) 시작과 설정 화면을 열 때 부른다.
- 위젯 상태(선택, 비교, 자동모드 저장 선택)가 없어진 id를 가리키면 기존 `sanitizeSelection` 규칙대로 지운다. IXIC 선택을 NDX로 옮기지는 않는다.
- `builtInQuotes`: data.json의 기본 지표 중 `BUILT_IN_NAMES`에 있는 id만 그린다. 위젯과 설정 화면이 함께 쓴다. 새 APK가 옛 13개 data.json을 받아도 IXIC·ES·NQ 타일이 생기지 않아 **APK를 먼저 배포해도 된다**. 그동안 NDX 타일은 없고 수집기 배포 뒤 나타난다.
  - 대가: 앞으로 수집기에 새 기본 지표를 더하면 APK도 같이 바꿔야 타일이 보인다.
- 나스닥 종합은 추가 종목으로 넣을 수 있다. `^IXIC`가 기본 심볼에서 빠져 `추가됨`으로 막히지 않고, Yahoo 검색 `quoteType=INDEX`·`^` 규칙과 추가 확인(`INDEX`)을 지금 그대로 통과한다.

## 4. 합친 24시간 차트 계산 (`model/Combined.kt`)

### 4.1 입력

`combine24h(spot: SpotSeries, futures: FuturesSeries, now: Long, rollAt: Long?)`

- `SpotSeries`: 현물 5분봉 `(시각, 종가)`, 날짜별 정규장(`tradingPeriods`, 없으면 `newYorkSessions`가 America/New_York 09:30~16:00으로 계산), `previousClose`.
- `FuturesSeries`: 선물 5분봉 `(시각, 시가, 종가)`, 계약 이름.
- 시각은 모두 초 단위 epoch. 시간대는 `America/New_York`, `Asia/Seoul`을 직접 쓰고 기기 시간대를 쓰지 않는다.

### 4.2 정규장과 기준(base)

- 정규장마다 현물 봉이 있는 것만 쓴다. 끝은 정규장 끝과 마지막 봉 중 늦은 쪽.
- 기준 `(Tc, Sc, Fc)`: 마지막 현물 봉 시각·종가와 **같은 시각** 선물 종가. 없으면 앞뒤 5분 안의 가장 가까운 봉(같은 거리면 앞 봉). 그것도 없으면 그 장 뒤 장외 구간은 그리지 않는다.

### 4.3 값

- 정규장 안([개장, 끝]): 현물 종가. 그 시간의 선물 봉은 버린다(진행 중인 장도 16:00까지 버린다).
- 장외 선물 봉 t: t보다 먼저 끝난 가장 최근 정규장의 기준으로 `Sc × F(t) / Fc`. 앞선 정규장이 자료에 없으면 그리지 않는다.
- 개장 전환: 마지막 환산 봉 다음에 개장 현물 봉으로 바로 잇는다. 지난 값을 고치지 않는다.
- 공백: 이웃한 점이 10분(600초)을 **넘게** 떨어지면 선을 끊는다(`breaks`). 정비 시간·주말·휴장은 끊기고, 선물 자정의 10분 빈 봉은 잇는다.
- 값은 소수 둘째 자리로 반올림해 저장한다.

### 4.4 창, 기준선, 등락

- 창: `끝 = min(now, 마지막 점 + 5분)`, `시작 = 끝 − 24시간`. 범위 밖 점은 버리고 2개 미만이면 null.
- 기준선: 끝 이전에 끝난 가장 최근 정규장의 종가.
  - 그 정규장이 자료의 마지막 장 바로 앞 장이면(지금 장중) `previousClose`(그 장의 공식 종가)를 쓴다. 자료 속 그 장의 마지막 봉은 15:55 봉이라 공식 종가와 0.02% 정도 다를 수 있어서다. 이렇게 하면 장중 차트 등락률이 카드 등락률과 같다.
  - 끝난 정규장이 없으면 `previousClose`, 그것도 없으면 null.
- 현재값 = 마지막 점, 변화량·등락률 = 기준선 대비, 최저·최고 = 창 안의 값.

### 4.5 롤오버 [미확인]

- 기준은 매 갱신 같은 응답 안에서 다시 계산하고 저장하지 않는다. Yahoo가 한 계약의 연속 자료를 주면 이것만으로 처리된다.
- 기기는 지난 결과의 계약 이름(`combined.contract`)을 기억한다. 이번 이름과 다르면 `roll_at = 지금`으로 정하고, 이름이 같은 동안 7일 유지한다(`rollAtFor`).
- `roll_at`이 있으면 `Tc < roll_at`인 정규장 뒤 장외 구간에서, `roll_at` 이전에 끝난 공백(10분 초과)마다 `Fc ← Fc × (공백 뒤 첫 봉 시가 / 공백 앞 마지막 봉 종가)`. 공백 뒤 시가가 공백 앞 값에 이어진다.
- 명세는 "이름이 바뀐 갱신에서"만 보정한다. 그 다음 갱신에서 이름이 같아 보정이 빠지면 계단이 다시 보이므로, 바뀐 시각을 기억해 옛 계약 기준이 남아 있는 동안 계속 보정한다(명세와 다른 점).
- 고정 데이터 테스트로만 확인했다. 2026-12-18(셋째 금요일) 만기 무렵 실제로 확인한다. 선물을 못 받은 갱신이 끼면 이름 기억이 지워져 그 주기의 계단은 보정되지 않는다.

### 4.6 출력 (`CombinedChart`, `Quote.combined`)

| 필드 | 위치 | 형식·단위 | 빈 값 | 만드는 곳 | 읽는 곳 | 옛 APK 영향 |
| --- | --- | --- | --- | --- | --- | --- |
| `combined` | `quotes[]` (GSPC, NDX만) | 객체 | 기본값 `null` | 기기(`applyLiveQuotes`) | `MarketWidget` | 없음(수집기는 보내지 않음, 기기 캐시 전용) |
| `combined.times` / `values` / `converted` | `combined` | 초 epoch / 지수값 소수 2자리 / 환산 여부, 1:1 | 빈 목록 | 기기 | 차트 | - |
| `combined.breaks` | `combined` | 점 위치(그 앞에서 끊음) | 빈 목록 | 기기 | 차트 | - |
| `combined.start`, `end` | `combined` | 초 epoch, 창 | 0 | 기기 | 가로축 | - |
| `combined.sessions` | `combined` | `[{start,end}]` 창 안 정규장 | 빈 목록 | 기기 | 배경 띠 | - |
| `combined.baseline`, `price`, `change`, `change_pct`, `low`, `high` | `combined` | 지수값, % | 0 | 기기 | 머리줄, 점선 | - |
| `combined.contract`, `roll_at` | `combined` | 계약 이름, 초 epoch | null | 기기 | 롤오버 보정 | - |

- 원시 5일 봉은 캐시에 넣지 않는다. 결과는 지수 하나에 약 7KB.
- 선물(또는 현물 5일 봉)을 못 받은 갱신에서는 `combined = null`로 지운다. 그러면 기존 오늘 차트를 그린다. 모든 시세를 못 받은 갱신은 데이터 전체를 그대로 둔다(기존 규칙).

## 5. 데이터 받기 (`data/Repository.kt`)

- S&P500·나스닥100: 시세(`range=5d&interval=1d`)는 그대로. 5분봉을 `range=1d` 대신 `range=5d`로 받는다.
  - 카드 작은 차트와 오늘 차트 필드(`intraday`, `intraday_times`, `session_start/end`)는 `parseLastSession`이 마지막 정규장만 뽑아 v1.0과 같다.
  - 같은 갱신에서 선물 `range=5d&interval=5m`을 받는다. 같은 차트 엔드포인트다.
- 다른 지표와 추가 종목은 그대로 `range=1d`.
- 받기는 지표마다 `Dispatchers.IO` 코루틴 안에서 한다(메인 스레드 아님). 갱신 1번의 요청 수는 26개에서 24개로 준다(카드 13 → 11개, 선물 5분봉 2개 추가). 받는 양은 5일 응답 때문에 압축 전 약 140KB 늘어난다(현물 5일 약 34KB, 선물 5일 약 60KB씩) [실측 응답 크기].
- `refresh`는 덮어쓰기 전 캐시를 읽어 계약 이름을 이어 쓴다. data.json에는 `combined`가 없기 때문이다.

## 6. 그리기

- S&P500·나스닥100에서 `오늘`이고 `combinedChartFor`가 결과를 주면 합친 차트, 아니면 기존 오늘 차트.
- 가로축: 창 24시간의 시각 비율. 눈금은 `sessionTicks`(서울 시간, 24시간이면 4시간 간격, 예: `23:00 04:00 08:00 12:00 16:00 20:00 23:00`).
- 정규장 띠: 그림 영역 높이로 흰색 약 8% 알파(`0x14FFFFFF`). 낙폭 구간 칠(파랑 12%)과 겹치지 않는 중립 톤.
- 선 끊기: `renderLine(breaks = …)`. 구간마다 선과 면을 따로 닫는다. 기본값(빈 목록)이면 v1.0과 같은 경로다.
- 점선 문구 `전일 7,592`(기존 `formatPrice`), 머리 배지 등락, 최저·최고, 아래 `현재`는 합친 값. 아래 왼쪽은 `24시간 전`.
- 마지막 점이 환산값이면 머리줄에 `선물 환산 HH:mm`(그 봉의 서울 시각)을 작게 쓴다.
- 카드 숫자·등락률은 현물 시세 그대로다. **장외에는 카드 숫자와 차트 현재값이 다르다.**
- 작은 차트, 1개월~MAX, 비교(오늘은 비교 안 함), 자동모드, 설정은 바꾸지 않는다.
