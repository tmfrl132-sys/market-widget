# 경제지표 위젯

안드로이드 태블릿 홈 화면에 한·미 시세 13개와 다가오는 경제지표 발표 일정을 보여주는 위젯. 앱 설정 화면에서 보일 지표를 고르고 종목을 최대 8개 더할 수 있다.

기본 지표(처음 타일과 자동모드 순서): 코스피, 코스닥, S&P500, S&P 선물, 나스닥, 나스닥 선물, VIX, 원/달러, 달러인덱스, 미 10년물, WTI, 금, 비트코인.

- 설계: `docs/superpowers/specs/2026-10-30-market-widget-design.md`, v0.9 변경은 `docs/superpowers/specs/2026-11-06-v0.9-indicators.md`, v1.0 변경(설정 화면, 종목 추가, 잠수 차트, 기본 크기)은 `docs/superpowers/specs/2026-11-12-v1.0-settings.md`
- 계획: `docs/superpowers/plans/2026-10-30-market-widget.md`
- 데이터: https://tmfrl132-sys.github.io/market-widget/data.json (30분마다 갱신)

## 태블릿에 설치하기

1. 태블릿 브라우저로 [Releases](https://github.com/tmfrl132-sys/market-widget/releases/latest)를 열고 `market-widget-v….apk`를 받는다.
2. 받은 파일을 연다. "출처를 알 수 없는 앱" 허용 화면이 나오면 브라우저(예: Chrome)에 허용을 켠다.
3. 설치한 뒤 홈 화면 빈 곳을 길게 누르고 **위젯 → 경제지표**를 끌어다 놓는다. 또는 "경제지표" 앱 아이콘을 눌러 설정 화면 아래의 **홈 화면에 위젯 추가**를 누른다. 새로 놓는 위젯은 6×4칸 크기로 놓인다(홈 화면 칸이 그보다 적으면 홈 화면이 줄여서 놓는다).
   - **이미 놓아 둔 위젯은 크기가 바뀌지 않는다.** 앱을 업데이트해도 그대로다. 큰 크기를 쓰려면 위젯을 길게 눌러 테두리를 끌어 늘리거나, 설정 화면의 **홈 화면에 위젯 추가**로 새로 놓고 옛 위젯을 지운다. 새로 놓은 위젯은 기간·자동모드·로그 같은 위젯별 선택이 처음 값으로 시작한다.
4. 오른쪽 위 ⟳를 누르면 현재 시세를 바로 받는다(코스피·코스닥은 네이버, 나머지는 Yahoo). 화면이 켜져 있으면 5분마다 저절로 받는다. 타일의 작은 차트는 그 시장의 최근 장 흐름이다. 아래 큰 오늘 차트처럼 가로축이 장 시작부터 장 끝까지 고정되어 있어 지금 시각까지만 그려진다(눈금 글자와 세로선은 없다). 장 시간을 못 받았거나 봉이 장 시간 밖이면 가로 전체로 늘려 그린다. 시세 타일을 누르면 아래에 차트가 나오고, 다시 누르면 발표 일정으로 돌아간다. 크기를 세로로 줄이면 시세만 보인다.
5. **자동** 버튼을 켜면 위젯에 보이는 지표를 설정 화면의 순서대로(처음에는 코스피부터 비트코인까지) 1분마다 차트가 바뀐다. 타일을 누르면 그 종목으로 건너뛴다. 끄면 켜기 전 화면으로 돌아간다. 화면이 꺼져 있으면 멈췄다가 켜질 때 이어진다.
6. 차트 기간은 오늘·1개월·3개월·1년·5년·MAX다. 차트 칸의 `고점 대비`는 현재 값이 기간 내 고점에서 얼마나 내려왔는지, `MDD`는 기간 내 가장 큰 낙폭이고, 그 뒤에 최대 낙폭 구간이 `7/10 고점 → 8/5 바닥 → 11/3 회복`(회복하지 못했으면 `미회복`)으로 나온다. 날짜는 1·3개월 `M/d`, 1년 `yy.M.d`, 5년·MAX `yyyy.M`이다. **잠수 차트**: 1개월~MAX에서 가격 차트 아래에 고점 대비 낙폭을 0% 선에서 아래로 채운 면적으로 그린다. 1개월~5년은 그 기간 첫 값부터의 고점 기준이고, MAX는 전체 일봉으로 계산한 값이다. 두 차트는 점이 1:1이고 오른쪽 숫자 칸 폭이 같아서 같은 날짜가 세로로 같은 위치에 있다(세로 보조선이 위아래로 이어진다). 최대 낙폭 구간(고점부터 회복까지, 회복하지 못했으면 오른쪽 끝까지)은 위아래 차트 모두 옅은 파란색으로 칠하고, 가격 차트에 고점(흰 점)과 바닥(파란 점)을 찍는다. 잠수 차트에는 바닥 `MDD -34.2%`, 마지막 값 `현재 -5.1%`를 적고, MAX에서는 외환위기·닷컴버블·서브프라임·코로나 지점도 표시한다(`collector/config.py`의 `MARKET_EVENTS`, 바닥과 같은 점이면 `외환위기 -64.7% · MDD`처럼 하나로). 차트 칸이 낮으면 잠수 차트를 빼고 가격 차트에 구간 칠과 점만 남긴다. 오늘 차트와 비교 중에는 잠수 차트·구간·MDD 줄이 없다. 원/달러, 달러인덱스, 미 10년물, VIX(추가 종목은 VIX·금리 지수)는 낙폭을 표시하지 않는다. 큰 차트 아래쪽에는 가로축 글자가 나오고, 그 자리에 세로 보조선이 그어진다. 날짜 눈금은 달력 경계의 첫 거래일에 놓인다. 1개월은 매주 첫 거래일(`10/12`), 3개월은 매달 첫 거래일(`11/2`), 1년은 분기 첫 거래일(`26.4`), 5년은 매해(`2023`), MAX는 간격 해의 배수인 해(`2000`)이고, 값이 짧아 경계가 2개 미만이면 균등 간격으로 놓는다. 잠수 차트가 함께 나오면 글자는 아래 잠수 차트에만 표시하고 가격 차트에는 세로 보조선만 그린다. 오늘 차트의 가로축은 그 시장의 장 시작부터 장 끝까지이고 시각은 서울 시간이다. 장이 진행 중이면 지금까지 지난 만큼만 그려진다(코스피는 6시간 30분 장이라 10시에 약 15%). 시각이나 장 시간을 못 받았거나, 봉의 절반을 넘게 장 시간 밖이거나, 날짜가 없으면 가로축 글자 없이 가로 전체에 그린다.
7. 5년·MAX에서는 **로그** 버튼으로 눈금을 바꾼다. 차트 첫 값이 `10⁰`이고 Y축은 그 값의 배수다(`10²`는 첫 값의 100배). 10배가 안 되는 차트는 `10^0.2`처럼 소수 지수를 쓴다.
8. **타일 배치**: 한 줄 타일 수는 위젯 폭에 맞춰 4~7개다. 기본 13개는 폭이 약 700dp 이상이면 두 줄(7·6)이고, 좁으면 5·5·3이나 4·4·4·1처럼 줄이 늘고 그만큼 차트 칸이 낮아진다. 마지막 줄의 빈 칸은 비워 두어 세로 열을 맞춘다. 켜 둔 지표가 1~4개여도 한 줄은 4칸이라 타일 하나가 위젯 폭 전체로 늘어나지 않는다. 지표가 많을수록(최대 21개) 타일 줄이 늘고 차트 칸이 낮아진다.
9. **장 상태**: 타일 이름 오른쪽에 그 숫자가 어떤 값인지 표시한다. 초록 점 `●`은 장중(마지막 봉이 30분 안), `마감`은 오늘 장이 끝났거나 30분 넘게 새 봉이 없음, `장 전`은 다음 장 시작 전, `휴장`은 시장 현지 주말이거나 평소 개장 30분 뒤에도 새 장이 없음이다. 차트 머리줄에는 `마감 15:30`, `장 전 · 23:30 시작`, `휴장 · 11/6 값`처럼 서울 시각과 함께 나온다. 기준 시각은 위젯 위쪽의 "HH:mm 기준"이다. 비트코인은 늘 장중이고 값이 30분 넘게 오래되면 표시하지 않는다. 휴장일 달력이 없어서 평일 공휴일 개장 30분 전까지는 `장 전`으로, 개장이 늦춰진 날(수능일, 새해 첫 거래일)의 평소 개장 30분 뒤부터 실제 개장 전까지는 `휴장`으로 잘못 보일 수 있다.
10. **큰 움직임 강조**: 오늘 등락률이 그 지표의 기준 이상이면 타일 테두리와 등락 배지가 진한 빨강(상승) 또는 파랑(하락)이 된다. 기준은 수집기가 `max(기본값, 2.5 × 최근 60거래일 하루 등락폭 중앙값)`으로 정해 `big_move_pct`로 보낸다. 기본값은 `collector/config.py`의 `BIG_MOVE_BASE`(코스피 2.0%, VIX 10.0%, 달러인덱스 0.7% 등)이고, 바꿔도 APK를 다시 깔 필요가 없다. 직전 값(흐린 타일)은 강조하지 않는다.
11. **두 지표 겹쳐 보기**: 차트를 연 상태에서 기간 줄 끝의 **비교**를 누르면 버튼이 파랗게 바뀌고 `비교할 지표 타일을 누르세요`가 나온다. 다른 타일을 누르면 두 지표가 같은 시작점 100에서 출발하는 선 두 개(주 지표 흰색, 비교 지표 주황)로 겹쳐 그려지고, 범례에 각 지수값과 시작 대비 등락이 나온다. 다른 타일을 누르면 비교 대상은 그대로 두고 주 지표만 바뀐다. **비교 ✕**를 누르거나 차트를 누르면 끝난다. 1개월~MAX에서만 겹쳐 그리고(오늘은 시장마다 장 시간이 달라 주 지표만 그린다), 5년·MAX에서 로그를 켜면 비교에도 적용된다. 자동모드에서는 비교 버튼이 숨고 비교가 꺼진다.
12. **설정 화면**: 런처의 "경제지표" 아이콘이나 위젯 머리줄의 **설정** 버튼(자동과 ⟳ 사이)을 누르면 열린다. 태블릿 가로 화면에서는 왼쪽에 "위젯에 보일 지표", 오른쪽에 "종목 추가"가 나란히 나오고, 좁으면 위아래로 쌓인다. 바꾸면 바로 저장되고 1~2초 안에 위젯이 다시 그려진다(저장 버튼 없음). 설정은 모든 위젯에 같이 쓰인다.
    - **켜기/끄기**: 줄 오른쪽 스위치. 켜진 지표가 1개뿐이면 그 스위치는 끌 수 없다(`최소 1개는 켜 두어야 합니다`). 기본 13개는 지울 수 없고 끄기만 된다.
    - **순서**: 줄 왼쪽 ▲▼를 누르면 한 칸씩 옮겨진다. 위젯 타일과 자동모드가 이 순서를 따른다.
    - **기본값으로**: 순서를 처음대로 되돌리고 모두 켠다. 추가한 종목은 지우지 않는다.
    - **종목 추가**: 검색 칸에 이름이나 코드(예: `삼성전자`, `005930`, `AAPL`, `nikkei`, `ETH`)를 넣으면 0.4초 뒤 후보가 나온다. **추가**를 누르면 시세를 받을 수 있는지 확인한 뒤 목록 맨 아래에 켜진 채로 붙고, 위젯에 `-` 타일이 바로 생겼다가 보통 1분 안에 값과 차트가 채워진다. 대상은 한국·미국 주식, ETF, 지수, 암호화폐다(선물, 환율, 그 밖 나라의 개별 주식, KONEX, 펀드는 나오지 않는다). 최대 8개까지 추가할 수 있고, 8개가 차면 **추가** 버튼이 막힌다. 이미 있는 종목(기본 지표 포함)은 `추가됨`으로 나온다.
    - **검색 규칙**: 한글 검색어는 네이버에서만 찾는다. 영문·숫자는 네이버와 Yahoo를 함께 찾고 네이버 결과(한글 이름)를 먼저 보인다. 암호화폐는 네이버에 없어 영문(예: `ETH`)으로 검색한다.
    - **삭제**: 추가한 종목 줄의 **삭제**를 누르고 확인하면 지운다.
    - **상태 글자**: 추가 종목 줄 아래에 `받는 중`, `23:05 받음`, `받지 못함 · 다시 시도 중`이 나온다.
    - 추가 종목도 기본 지표와 같은 기준으로 시세, 오늘 차트, 1개월~MAX 차트, 고점 대비·MDD·잠수 차트, 장 상태, 큰 움직임 강조를 보여 준다(사건 표시는 없다). 값은 태블릿이 Yahoo에서 직접 받고, 한국 주식·ETF는 평일 09:00~16:00에 네이버의 정규장(09:00~15:30) 1분봉 값을 쓴다(넥스트레이드 시간외 값은 쓰지 않는다). 1년·5년 기록은 6시간마다, 전체 기간은 7일마다 새로 받는다. 큰 움직임 기준의 기본값은 주식 3.0%, ETF 2.0%, 지수 1.5%, 암호화폐 5.0%이고 최근 60거래일 움직임에 맞춰 올라간다. 꺼 둔 추가 종목은 받지 않는다.

새 버전도 같은 방법으로 받아 설치하면 덮어쓴다. 서명 키가 같아서 지우지 않아도 된다. 설정과 추가 종목은 앱 업데이트 뒤에도 남는다.

## 관리

- **값이 오래됐을 때**: 위젯 아래 갱신 시각에 날짜가 붙어 있으면 수집이 멈춘 것이다. 공개 저장소는 60일 동안 활동이 없으면 GitHub가 예약 실행을 끈다. 저장소 **Actions → collect → Enable workflow**로 다시 켠다.
- **수동 수집**: `gh api -X POST repos/tmfrl132-sys/market-widget/actions/workflows/collect.yml/dispatches -f ref=main -f "inputs[force]=true"`
- **발표 일정표**: `collector/schedule.json`. FOMC(연준 공식 일정)와 한국은행 금통위 날짜를 매년 갱신한다. 2027년분까지 들어 있다.
- **새 APK 배포**: `git tag v0.1.1 && git push origin v0.1.1`
- **서명 키 백업**: `C:\Users\tmfrl\market-widget-keystore\` (저장소 밖). 잃어버리면 다음 업데이트 때 앱을 지우고 다시 깔아야 한다.

## 개발

```bash
uv run pytest
```

안드로이드 테스트와 빌드는 GitHub Actions(`android.yml`)에서만 돈다.
